Let's start with the absolute foundation: the PostgreSQL schema (init.sql) and the Python Generator (generate_synthetic_data.py).

Technical Decision: Database Schema Design
Problem: We need to store 10 related entities (Customer, Product, Survey, Review, etc.) ensuring strict referential integrity, supporting lifecycle states, and handling many-to-many relationships for themes.

Approach: We will write a strict PostgreSQL schema using VARCHAR for primary keys, native ENUM types for static statuses, and bridge tables for themes.

Reasoning: The challenge demands deterministic IDs (e.g., SUR-2026-000001). Using standard auto-incrementing integers (SERIAL) will break reproducibility when we run the Python script multiple times. VARCHAR ensures our generated IDs map perfectly into the database.

Alternatives: Document databases (MongoDB) could store reviews as nested objects.

Trade-offs: PostgreSQL requires strict schema enforcement upfront, which slows initial development but completely prevents orphan records and data anomalies (a major grading criteria for this challenge).

Validation: We will try to insert a dependent record (like a Review) with a non-existent customer_id. The database must immediately reject it with a Foreign Key Violation error.

-- 10. ActionItem (Generated from recurring themes)
CREATE TABLE action_items (

def generate_customers():

    ids = [f"CUST-{str(i).zfill(6)}" for i in range(1, n_cust + 1)]
    firsts = ["Aarav", "Priya", "Rohan", "Ananya", "Vikram", "Neha", "Kabir", "Meera"]

    })
    customers.to_csv(f"{OUTPUT_DIR}/customers.csv", index=False)
    return customers

def generate_reviews(customers):

Problem: Our backend needs to query a PostgreSQL database containing tens of thousands of records without blocking the Node.js single-threaded event loop.
Approach: We will build an Express server using the pg (node-postgres) library to manage a connection pool.

Alternatives: We could use an ORM like Prisma or Sequelize.

This is a great idea. A professional SaaS dashboard isn't just a grid of charts—it needs a polished footer for compliance, documentation, and support links, and the interactions should feel fluid and deeply responsive.

Technical Decision: Advanced Animation & Layout
Problem: The user wants the dashboard to feel "more animated" and professional without feeling overwhelming or laggy. It also needs a standard enterprise footer.

Approach: We will enhance Framer Motion by switching from linear transitions to Spring physics (which gives a natural, bouncy feel). We will add whileHover and whileTap states to all interactive elements (cards, buttons) so they respond to the user's mouse. We will also add a sleek, semantic <footer> component at the bottom of the scrollable area.

Reasoning: Spring animations feel much more premium than standard CSS ease-in-out. By adding micro-interactions to the KPI cards and chart wrappers, the dashboard will feel alive.

Validation: When you move your mouse over the cards, they should gently lift off the page. The sidebar items will load in a staggered sequence, and the footer will slide up gracefully at the bottom.

Technical Decision: Upgrading to a Composed Chart
Problem: The previous line chart only plotted Positive and Negative lines. It didn't clearly show the exact volume side-by-side for a specific month, and it completely hid the Neutral/Mixed and Total counts.

Approach: We will upgrade the trends chart from a basic LineChart to a Recharts ComposedChart.

Reasoning: A ComposedChart lets us layer different types of graphs on top of each other. This gives the product team a complete, instant visual breakdown of exactly what happened every single month.

// Custom hook/component for counting up numbers dynamically
const AnimatedCounter = ({ value }) => {
  const [count, setCount] = useState(0);
  useEffect(() => {
    let start = 0;
    const end = parseInt(value, 10);
    if (isNaN(end) || end === 0) {
      setCount(end || 0);
      return;
    }
    const duration = 1200; 
    const stepTime = Math.abs(Math.floor(duration / 30));
    const increment = Math.ceil(end / 30);
    
    const timer = setInterval(() => {
      start += increment;
      if (start >= end) {
        setCount(end);
        clearInterval(timer);
      } else {
        setCount(start);
      }
    }, stepTime);
    return () => clearInterval(timer);
  }, [value]);
  return <>{count.toLocaleString()}</>;
};

However, as your senior mentor, I need to raise an important design flag here before we throw WebGL and three.js at this. Let's break this down using our framework.

Problem: How do we introduce 3D elements into a B2B Customer Intelligence Dashboard to make it visually stunning without ruining its primary purpose (reading data)?

Approach: We will implement 3D CSS Spatial Transforms (Parallax Tilt) on the dashboard elements, rather than rendering literal 3D bar charts or using WebGL.

Reasoning: In data science and analytics, true 3D charts (like 3D pie charts or 3D bars) are heavily discouraged because perspective distortion makes it impossible for the human eye to accurately compare data sizes. By applying 3D physics to the UI cards themselves instead of the charts, we get that premium, spatial "Next-Gen" feel while keeping the data 100% accurate and readable.

Alternatives: We could use @react-three/fiber to build a literal 3D room or 3D globe.

Trade-offs: True WebGL/Three.js adds massive bundle size (slower load times) and can drain laptop batteries or cause lag on weaker machines. CSS-based 3D transforms using Framer Motion provide 80% of the visual "wow" factor with 0% of the performance hit.

Validation: When you move your mouse over the KPI cards and the sidebar, they will physically tilt in 3D space tracking your cursor, with lighting reflections shifting across the glass surfaces.

Let's upgrade our KpiCard component to a ThreeDimensionalCard using Framer Motion's spatial values.

  const [count, setCount] = useState(0);

    let start = 0;
    const end = parseInt(value, 10);
    if (isNaN(end) || end === 0) {
      setCount(end || 0);
      return;
    }
    const duration = 1200; 
    const stepTime = Math.abs(Math.floor(duration / 30));
    const increment = Math.ceil(end / 30);
    
    const timer = setInterval(() => {
      start += increment;
      if (start >= end) {
        setCount(end);
        clearInterval(timer);
      } else {
        setCount(start);
      }
    }, stepTime);
    return () => clearInterval(timer);
  }, [value]);
  return <>{count.toLocaleString()}</>;
};

// 2. TRUE 3D SPATIAL CARD COMPONENT
function ThreeDimensionalCard({ icon, color, title, value, trend }) {
  const ref = useRef(null);
  
  // Mouse position values
  const x = useMotionValue(0);
  const y = useMotionValue(0);
  
  // Spring physics for smooth return
  const mouseXSpring = useSpring(x, { stiffness: 150, damping: 15 });
  const mouseYSpring = useSpring(y, { stiffness: 150, damping: 15 });
  
  // Transform mouse position to 3D rotation degrees
  const rotateX = useTransform(mouseYSpring, [-0.5, 0.5], ["12deg", "-12deg"]);
  const rotateY = useTransform(mouseXSpring, [-0.5, 0.5], ["-12deg", "12deg"]);

  const handleMouseMove = (e) => {
    if (!ref.current) return;
    const rect = ref.current.getBoundingClientRect();
    const width = rect.width;
    const height = rect.height;
    const mouseX = e.clientX - rect.left;
    const mouseY = e.clientY - rect.top;
    const xPct = mouseX / width - 0.5;
    const yPct = mouseY / height - 0.5;
    x.set(xPct);
    y.set(yPct);
  };

  const handleMouseLeave = () => {
    x.set(0);
    y.set(0);
  };

  const colorMap = {
    blue: 'bg-blue-50 text-blue-600',
    indigo: 'bg-indigo-50 text-indigo-600',
    emerald: 'bg-emerald-50 text-emerald-600'
  };

  return (
    <motion.div
      ref={ref}
      onMouseMove={handleMouseMove}
      onMouseLeave={handleMouseLeave}
      style={{ rotateX, rotateY, transformStyle: "preserve-3d" }}
      variants={{hidden: {y: 40, opacity: 0}, visible: {y: 0, opacity: 1}}}
      className="relative bg-white/80 backdrop-blur-2xl p-8 rounded-[2rem] shadow-xl border border-white flex flex-col justify-between group cursor-crosshair"
    >
      {/* 3D Floating Elements inside the card */}
      <motion.div style={{ translateZ: "50px" }} className="flex justify-between items-start mb-8 z-10">
        <div className={`p-4 rounded-2xl ${colorMap[color]} shadow-lg`}>
          {React.cloneElement(icon, { className: 'w-7 h-7' })}
        </div>
        <span className="text-xs font-black px-4 py-2 bg-slate-900 text-white rounded-full uppercase tracking-widest shadow-md">
          {trend}
        </span>
      </motion.div>
      
      <motion.div style={{ translateZ: "30px" }} className="z-10">
        <h3 className="text-slate-500 font-extrabold text-sm mb-2 uppercase tracking-widest drop-shadow-sm">{title}</h3>
        <p className="text-5xl font-black text-slate-900 tracking-tighter drop-shadow-md">
          <AnimatedCounter value={value} />
        </p>
      </motion.div>

      {/* Dynamic 3D Glare Effect */}
      <motion.div 
        style={{ 
          background: "linear-gradient(105deg, transparent 20%, rgba(255,255,255,0.6) 25%, transparent 30%)",
          x: useTransform(mouseXSpring, [-0.5, 0.5], ["-100%", "100%"]),
          translateZ: "60px"
        }} 
        className="absolute inset-0 pointer-events-none rounded-[2rem] opacity-50 group-hover:opacity-100 transition-opacity"
      />
    </motion.div>
  );
}
